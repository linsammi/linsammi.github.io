## Learning Something New

Before taking ICS 314, I barely knew anything about HTML and CSS, so learning Bootstrap 5 was definitely challenging. I originally thought using a framework would make web development easier, but I quickly realized there was another learning curve involved. Understanding all the different Bootstrap classes was probably the hardest part for me, especially since I was still learning the basics of HTML and CSS.

However, after working on several projects, I started to understand why developers use frameworks. One thing I really liked about Bootstrap was how professional it could make a website look, even with my limited experience.

## Why Use Bootstrap?

Bootstrap provides prebuilt components that make designing websites faster and more consistent. Instead of writing everything from scratch, developers can use existing classes for navigation bars, spacing, and responsive layouts.

I also learned that responsive design is important because websites need to work on different screen sizes. Bootstrap makes this easier, although customizing certain elements can still be confusing.

From a software engineering perspective, frameworks also help developers maintain consistency and collaborate because everyone can use the same components and styling conventions.

## My Experience with Bootstrap 5

Throughout this module, I recreated several websites, including Island Snow, Murphy's Bar and Grill, Banyans, and CSM Hawaii.

My favorite project was recreating the CSM Hawaii website. I enjoyed seeing how the images, navigation, and layout came together to make something that looked like an actual professional website. It was satisfying to see how much I could accomplish after barely knowing HTML and CSS.

I also worked on the Banyans website, where I had to adjust the navigation menu to collapse on smaller screens. This showed me that Bootstrap doesn't automatically solve every problem, and understanding how to customize components is still important.

## Final Thoughts

Overall, Bootstrap 5 was confusing at first, but I can see why developers use it. It makes websites look polished and provides tools that can save time once you understand them.

I'm still undecided whether I would use Bootstrap or regular HTML and CSS for future projects. I think both approaches have their advantages, and learning more about each will help me become a better developer.
