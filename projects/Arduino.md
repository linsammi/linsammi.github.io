The LED DJ Board is an embedded systems project I built using an Arduino Nano ESP32. The purpose of the project was to learn how a microcontroller can read analog inputs from physical components and use those values to control outputs.

For this project, I worked with a breadboard, potentiometers, resistors, LEDs, and jumper wires. I learned how analog input values can be converted into voltage values and how a potentiometer can be used as part of a voltage divider. I then used the values read by the Arduino to control physical LED outputs.

This project gave me more experience working with both hardware and software. I practiced building circuits, connecting components to the correct Arduino pins, and programming the microcontroller using CircuitPython. It helped me better understand how software can interact directly with physical hardware in an embedded system.
